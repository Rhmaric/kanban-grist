Kanban Grist

Cette vue affiche les lignes d’une table sous forme de tableau Kanban.

Pour commencer

  • Ouvrez le panneau de configuration
  • Accordez l’accès document complet, nécessaire pour créer, déplacer et supprimer des cartes.
  • Associez Titre de la carte à une colonne de type "Texte", et Grouper par à une colonne de type "Choix unique".
  • Ajoutez éventuellement des Propriétés visibles qui seront visibles dans les cartes.

L’ordre des cartes dans une colonne suit l’onglet Trier et filtrer de cette vue. Les colonnes du Kanban reprennent les choix, l’ordre et les couleurs définis par la colonne de type "Choix unique" sélectionnée. Pour modifier les intitulés de colonnes ou leur ordre, il faut modifier la colonne de type "Choix unique" sélectionnée.

Fonctionnalités

  • Glisser-déposer une carte d’une colonne à l’autre pour changer sa valeur de groupe.
  • Cliquer une carte la sélectionne : les autres vues de la page peuvent utiliser « Sélectionner par » sur ce Kanban.
  • Le bouton « + » (entête ou pied de colonne) crée une carte dans cette colonne ; une icône corbeille au survol la supprime après confirmation.
  • Le curseur « Taille » ajuste l’échelle d’affichage ; le réglage est mémorisé pour le document.

Recommandation

Associez ce Kanban à une vue Fiche sur la même page, placée sur le côté, avec « Sélectionner par » = ce Kanban.

Le Kanban sert à parcourir et déplacer les cartes ; la fiche affiche et modifie le détail (titre, propriétés).
